# Jogo Cast — Pong

Um jogo de Pong clássico em HTML5 Canvas + JavaScript puro, sem dependências.

## Como jogar

Abra `index.html` em qualquer navegador, ou sirva a pasta com um servidor estático:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Controles

- Jogador 1: `W` / `S`
- Jogador 2 (modo 2 jogadores): `↑` / `↓`
- `Espaço`: pausar/continuar

## Modos

- **1 Jogador**: você contra a CPU
- **2 Jogadores**: dois jogadores no mesmo teclado

Vence quem fizer 7 pontos primeiro.
